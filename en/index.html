    Post-mortems

    When it breaks for real.

    Three incidents on the SIOPS cluster. Symptom, diagnosis, fix, lesson — unfiltered.

    INC-01 · SEV1

    The cluster deadlocks itself on restartcontrol plane · etcd
    Symptom
    master-1 unreachable, API server flapping, cluster degraded.
    Diagnosis
    Undersized node: the OOM killer takes out etcd, quorum drops to 2/3. rke2-server waits on kubelet, which waits on etcd. Deadlock.
    Fix
    rke2-killall to break the loop, clean restart, then resize the master.
    Lesson
    You don't size a control plane like a worker.
    INC-02 · SEV1

    Three weeks without backups, and the jobs were greenbackups · restic · S3
    Symptom
    No recent snapshot. Yet every job reported success.
    Diagnosis
    S3 quota full. 486 GiB, 349 snapshots never pruned: the date in the dump name broke retention.
    Fix
    forget --group-by host + prune: 486 → 48 GiB. Script hardened with set -euo pipefail.
    Lesson
    A green job proves nothing. Monitor the age of the last restorable snapshot.
    INC-03 · SEV2

    The Vault unseal chain bites its own tailsecrets · Vault · SPOF
    Symptom
    Audit of Vault's boot chain after a platform restart.
    Diagnosis
    Auto-unseal depends on a single-replica secondary Vault. If it goes down, nothing unseals.
    Fix
    SPOF documented and added to the backlog with exit options. [TODO: status]
    Lesson
    A circular boot dependency only shows the day everything restarts at once.
