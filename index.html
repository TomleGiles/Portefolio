    Post-mortems

    Quand ça casse pour de vrai.

    Trois incidents vécus sur le cluster SIOPS. Symptôme, diagnostic, correctif, leçon — sans filtre.

    INC-01 · SEV1

    Le cluster se bloque lui-même au redémarragecontrol plane · etcd
    Symptôme
    master-1 injoignable, API server instable, cluster en fonctionnement dégradé.
    Diagnostic
    Nœud sous-dimensionné : l'OOM killer tue etcd, le quorum tombe à 2/3. rke2-server attend kubelet, qui attend etcd. Interblocage.
    Correctif
    rke2-killall pour casser la boucle, redémarrage propre, puis redimensionnement du master.
    Leçon
    Un control plane ne se dimensionne pas comme un worker.
    INC-02 · SEV1

    Trois semaines sans sauvegarde, et les jobs étaient vertsbackups · restic · S3
    Symptôme
    Aucun snapshot récent. Les jobs remontaient pourtant en succès.
    Diagnostic
    Quota S3 saturé. 486 GiB, 349 snapshots jamais purgés : la date dans le nom de dump cassait la rétention.
    Correctif
    forget --group-by host + prune : 486 → 48 GiB. Script durci avec set -euo pipefail.
    Leçon
    Un job vert ne prouve rien. On surveille l'âge du dernier snapshot restaurable.
    INC-03 · SEV2

    La chaîne de descellement Vault se mord la queuesecrets · Vault · SPOF
    Symptôme
    Audit de la chaîne de démarrage de Vault après un redémarrage de la plateforme.
    Diagnostic
    L'auto-unseal dépend d'un Vault secondaire en réplique unique. S'il tombe, plus rien ne se descelle.
    Correctif
    SPOF documenté et porté au backlog avec ses options de sortie. [TODO: statut]
    Leçon
    Une dépendance circulaire au démarrage ne se voit que le jour où tout redémarre.
